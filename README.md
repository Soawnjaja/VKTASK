# Файловое дерево

Небольшое React-приложение: показывает дерево файлов и папок, можно сворачивать папки, выделять файлы и удалять их через подтверждение.

Данные пока моковые — лежат в `src/lib/mokTree.tsx`, это не реальная файловая система.

## Запуск

```bash
cd tut
pnpm install
pnpm run dev
```

Vite выдаст адрес в терминале, обычно `http://localhost:5173`. Если порт занят — возьмёт следующий свободный.

Сборка и линт:

```bash
pnpm run build
pnpm run lint
```

## Что умеет

- **Папка** — клик сворачивает или разворачивает
- **Файл** — клик выделяет, справа виден размер
- **Двойной клик по файлу** — модалка «Удалить?»
- **Enter / Space** на файле — то же, что клик (выделение)

При первом открытии все папки развёрнуты.

## Как устроено

```
src/
├── main.tsx              — точка входа, рендерит FrontPage
├── index.css             — базовые глобальные стили
├── lib/
│   ├── mokTree.tsx       — типы узлов и мок-дерево
│   └── treeUtils.ts      — удаление файла, сбор id папок
└── pages/FrontPage/
    ├── index.tsx         — состояние: раскрытие, выбор, удаление
    ├── TreeView.tsx      — рекурсивный рендер дерева
    ├── ConfirmModal.tsx  — подтверждение удаления
    └── style.module.scss — стили страницы
```

Логика разделена просто: `FrontPage` держит состояние, `TreeView` только рисует, `treeUtils` — чистые функции над данными.

## Стек

React 19, TypeScript, Vite 8. Стили — CSS Modules + SCSS (`sass-embedded`).
